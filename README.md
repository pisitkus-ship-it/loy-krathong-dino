# ลอยกระทงกับไดโน

เกมเว็บเล็กๆ สำหรับคืนลอยกระทง: ประดิษฐ์กระทงของคุณเอง (ฐาน ใบตอง ดอกไม้ ธูปเทียน) เขียนคำอธิษฐาน แล้วปล่อยลงทะเลสาบในคืนยี่เป็งที่มีโคมลอยเต็มฟ้า และมีไดโนตัวโตลอยอยู่กลางน้ำคอยอวยพร

## วิธีเล่น

- เลือกวัสดุกระทง ใส่ชื่อเล่นและคำอธิษฐาน แล้วกด **ลอยกระทง**
- แตะท้องฟ้าเพื่อปล่อยโคม
- แตะไดโนเพื่อทักทาย
- แตะกระทงเพื่ออ่านคำอธิษฐาน
